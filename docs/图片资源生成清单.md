# 站点图片资源规划 & AI 生成提示词打包（全量扩充版）

> 整理人：蔡鑫｜日期：2026-09-29
> 用途：按本清单生成图片后，按「文件命名」列保存（透明素材 PNG，其余统一 WebP），交付开发即可接入。
> 覆盖范围：全局素材 + 首页 + 8 个工具页，**每个工具页统一配置 6-7 张图**（OG + Hero + 核心可视化 + 方法原理 + 真实场景）。

---

## 一、总体规范（所有图片必须遵循）

### 1. 风格策略（两类，视觉协调）

| 类型 | 适用图片 | 统一风格 |
|---|---|---|
| **A. 写实摄影** | OG 分享卡片、Hero 头图、场景图 | 高端健康品牌的专业编辑摄影：明亮自然光、浅景深、画面干净留白多 |
| **B. 3D 产品渲染** | 容器、物体、数据可视化素材 | 干净工作室 3D 渲染：柔和棚拍光、微妙投影、纯白/浅灰底、便于抠图 |

**贯穿两类的统一元素**：
- 品牌绿点缀色：`#16a34a`（翠绿），可出现在小道具、液体反光、毛巾、果蔬上
- 主色调：白、浅灰、清新绿、清透蓝（水体）
- 禁止画面内出现任何**文字、数字、字母、logo**（AI 生成的文字几乎必然出错；所有标注由前端代码叠加）
- 禁止：卡通贴纸感、廉价库存图感、杂乱背景、霓虹高饱和、人物正对镜头露脸摆拍；人物图必须自然、得体、非性化

### 2. 通用负面提示词（Negative Prompt，所有图都可追加）

```
text, words, letters, numbers, captions, watermark, logo, signature,
blurry, low quality, distorted, deformed, cluttered background,
cartoonish, oversaturated neon colors, cheap stock photo look
```

### 3. 尺寸与格式速查

| 用途 | 像素尺寸 | 比例 | 格式 |
|---|---|---|---|
| OG / 社交分享卡片 | **1200 × 630** | 1.91:1 | JPG/WebP（< 200KB） |
| 页面 Hero 大图 | **1600 × 900** | 16:9 | WebP（< 350KB） |
| 内容插图 / 场景图 | **1200 × 800** | 3:2 | WebP |
| 方形物体/可视化素材 | **1024 × 1024** | 1:1 | PNG（需透明底） |
| 纵向信息图 | **1200 × 1500** | 4:5 | WebP |

### 4. 性能与接入约定（图片虽多，分数不降）

- 每页仅 Hero 图即时加载（`priority`），其余全部 `loading="lazy"`
- 每张图显式声明 width/height，杜绝 CLS
- 单页 6-7 张图分布在不同滚动区块，首屏实际只下载 1 张，LCP 不受影响

```
/public/images/
  og/            og-<tool-slug>.jpg            （1200×630）
  heroes/        hero-<tool-slug>.webp         （1600×900）
  content/       <tool-slug>-<desc>.webp       （1200×800）
  objects/       <tool-slug>-<desc>.png        （1024×1024，透明底）
```
